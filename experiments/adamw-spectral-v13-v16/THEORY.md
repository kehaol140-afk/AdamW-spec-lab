# THEORY — adamw-spectral-v13-v16

## 1. 最初的科学问题与假设

**RQ**：AdamW 预条件更新 A 本身的谱/方向结构是否存在可操作、且不可被标量调参（LR/幅度/动量）解释的改进空间？

假设链（逐版收窄）：
- H-V13：训练后期的 A、其动量矩阵 H=m̂m̂ᵀ 类结构、当前梯度 g、更新-梯度夹角四状态可测且有结构（top-8 能量份额 21× 集中 → 谱结构存在）
- H-V14：对 A 施加有限 rank-1 谱修正能产生独立于标量的增量 → **被否证**（SCALE_RANGE_UNRESOLVED，CI 跨零）
- H-V15：整块**方向替换**（非谱形微调）在短视界产生信号 → 网格内成立（单 seed）
- H-V16：方向收益真实、必要、跨场景、跨 seed，且不被三个竞争解释（幅度轨迹/LR/动量历史）吸收 → A2/B/C 三层验证成立

## 2. 优化器与更新对象

- 底座：PyTorch AdamW 语义逐行复刻（betas=(0.9,0.999)、eps=1e-8、wd=0.01、grad clip 1.0、手写 cosine→0.1×peak；MiniMind h256/4L）
- 唯一作用对象：目标块 `layers.1.mlp.down_proj`（4,655,616 参数模型中的 (256,1024)... 实为该 MLP down 投影，占 4.22%）；其余参数块仅受全局幅度 b 缩放

## 3. 核心数学定义（逐行取自 `campaign_v16/core.py:385-470 apply_step`）

原生 AdamW 单步（bias-corrected）：

```
m₊ = β₁·m + (1−β₁)·g ;  v₊ = β₂·v + (1−β₂)·g²
A(p) = ( m₊/(1−β₁^t₊) ) / ( √(v₊/(1−β₂^t₊)) + ε )        # core.py:409-410, 无 lr 因子
```

方向族（D 的构造，core.py:412-424）：

```
S:  D = A(target)                                   # 原生动量商方向
F:  x = g_clip;      D = x · ‖A‖/‖x‖                # 当前梯度, n_a() 范数匹配 (core.py:418-419)
P:  x = g_clip / (√(v̂₊) + ε);  D = x · ‖A‖/‖x‖      # 单步预条件当前梯度 (core.py:420-423)
其中 n_a(x, a_norm) = x.double() * (a_norm/‖x‖)     # core.py:351-355, fp64 匹配, 零范数回退置零并记录
```

位移写回（opt.step() 之后做**验证性替换**，core.py:457-463）：

```
target 块: param += η·(A − a·D)      ⇒ 有效更新 = η·a·D        （η=当前 step 的 cosine LR）
其余块:    param += η·(1−b)·A_p      ⇒ 有效更新 = η·b·A_p
q_t ≐ η·a·‖D‖                                    # 逐 step 位移范数 (core.py:465)
```

A2 共同范数轨迹（q_override，core.py:425-436）：把本臂 D 重缩放至 `q_override/(η·a)`，使逐 step 位移范数精确等于源臂记录的 q 序列（实测逐 step |Δq|≤2.1e-9）→ 实现「方向×借用范数轨迹」2×2 分解。

统计例程（core.py:512-531）：token 加权 NLL = Σloss_sum/Σtoken_count；paired_bootstrap = doc 级重采样（numpy default_rng, seed 9071, 1000 次）对 pooled token 加权差取 2.5%/97.5% 分位。

## 4. 修改前后的精确数学差异

原生：update(target) = η·A(target)。修改后：update(target) = η·a·D_family，且 D_F/D_P 与 A **逐 step 范数相等**（‖D‖=‖A‖，fp64）——因此 S(a=1) 与原生逐位一致（复刻门利用此性质做位级验证），任何 NLL 差异只能来自**方向构成**或显式幅度 a≠1。V16-B 进一步把 b（其他块幅度）纳入网格以分离「目标块方向」与「全局幅度」。

## 5. 为什么需要这种修改

V13 测得 A 与 g 持续低对齐（cos≈0.4，66°）且 A 谱头部集中——即预条件更新大量保留了动量历史方向。问题是：这种历史方向是「必要的稳定器」还是「可替换的包袱」？S/F/P 三族在范数受控下给出最粗粒度但因果干净的回答：整块替换端点（V16_FINAL_MECHANISM Q5：谱形维度从未操作化，本线只做端点对比）。

## 6. 已验证 vs 仍假设

**已验证**（写进裁决）：
- 方向效应 ≥96% 保留于共同范数轨迹（A2，双向）
- 从头 2048 步 +0.12~+0.15 dev（B，18 分支）；跨 seed holdout +0.036~+0.151 3/3 同向（C）
- 低 β1（S5/S6/S7）、LR 外扩（0.0003）、A1 角点配方 (8,2)、幅度轨迹（A2）四个竞争解释全部失败
- 机制：收益不在对齐度/新鲜度（S6 cos(g,A)=0.93 仍差）；在「方向替换×幅度放大」组合

**仍假设/未排除**（不得写成结论）：
- a>8 更优解存在性（网格边界）；其他目标块/多块联合；谱形子空间增量；规模外推（→ direction 线）；P 的跨 seed（screen 缺陷未跑）
- 「方向」的操作定义=整块替换端点，与谱结构的分解未做
