## 2. 核心发现

1. **b（其他参数更新幅度）是第一主导因子**：H256 上 b=2 比 b=1 好 ~0.11 nats、比 b=0.5 好 ~0.24 nats——远大于任何方向差异；但 **H64 上完全反转**（b=2 最差）。短视界/长视界最优 b 相反（三族 H64 最优均为 b=1，H256 最优均为 b=2）。
2. **a（目标块幅度）单调推向边界**：每族内 a=1→8 单调改善但幅度小（H256 b=2 列 ~0.004）。**三族最优全部落在 (a=8, b=2) 角点 → `RANGE_UNRESOLVED`（冻结网格不自动外扩）**。
3. **F/P 方向收益是尺度条件性的**：同格配对 S−F（H256）：(1,1) 处 **F 比 S 差 0.0020**（P 差 0.0022）；仅在高放大的 a=8 行 F/P 反超（(8,2)：F +0.0028、P +0.0028；(8,1) H64：F +0.0039）。**不存在无条件的独立方向收益**——(1,1) 处方向改动本身是负收益，方向价值只在放大区间显现。
4. **F 与 P 几乎并列**（(8,2) 差 4.2e-5 nats，量级接近逐文档 bootstrap 噪声）：当前证据无法区分"归一化梯度方向"与"预条件归一化梯度方向"。
5. **H64 与 H256 的排序变化**：三族 best-b 从 H64 的 b=1 翻为 H256 的 b=2；F/P 的 H64 优势保留到 H256 仅在 a=8 行成立。短期局部收益（V15 观察）与 256 步终点收益**不是同一现象**。
6. **方向与幅度已发生混杂**：同 (a,b) 下 S/F/P 的 q_t 轨迹相近但不相同（(8,2)：S q̄=0.6385 / F 0.6613 / P 0.6691），且 A_norm 终值分化（S×1.094 / F×1.064 / P×1.075）——即"方向"比较自带幅度反馈差异，**必须由 A2 共同范数对照解耦**（协议已冻结该对照）。
7. 更新范数轨迹：所有分支 q_t 随 cosine 衰减（(8,2) q̄0.64→末段 0.26）；a=8 未引发范数爆炸或 zero_norm_fallback，数值健康。
