## 3. 代码和报告的问题

### 3.1 实际参数位移参考错误（确定的代码缺陷，不直接影响NLL）

`run_t2b_real.py:62-66`在`build_model()`随机初始化之后，尚未载入checkpoint就保存`anchor_params_cpu`。真正的`model.load_state_dict`出现在第69行的`fresh_restore()`。

因此`real_diag.csv`约81,179和148,582的平方距离，是训练终态到随机初始化的距离，不是这138步相对checkpoint的位移。不能用它证明真实轨迹移动很大或比较Muon/辅助组的续训距离。应从载入checkpoint后的独立副本建立参考；缺少真实终态时不能凭现表修回正确数值，不为修诊断默认重跑全部训练。

### 3.2 1.96 nats不是严格的同目标预测误差

`S_fin`在Q_select上评价，而实际V在Q_check上评价。二者相减包含模型近似误差与目标集差异，不能直接命名为绝对预测误差。

可以严格保留：在同一个Q_select上，原锚点日志V=2.397257，虚拟终点约4.224–4.249，明显恶化。也可以保留：S_fin对持出开发检查终点的排序信息弱。不能声称同目标的误差精确为1.96，除非取得实际终态在Q_select或虚拟终态在Q_check的对应值；本轮不为这一个数字重跑实验。

S_lin和S_fin都用Q_select，仍有-0.81/-0.90的排序相关。这说明一阶读出在虚拟系统内部就不再可靠，并非全由目标集切分导致。

### 3.3 NLL收缩不能归因到beta^128

beta^128=0.00140806，NLL候选极差比为0.07609/0.13374，不是同一量级的同一物理量。虚拟`M_tail_diff_sq`的比值确实符合beta^256=1.98264e-6，最大相对差约1.08e-5；这验证的是固定共同梯度下的虚拟动量关系。

真实分支保存的是各自M绝对范数，不是分支M差，也未保存step10的真实成对完整状态。故不能验证真实记忆差衰减率，不能写“排列差异主要是记忆激励、没有持久参数残留”。只能写：目标差异在共同尾部后显著缩小，原因未被唯一识别。

### 3.4 通过门逻辑错误（不改变本轮STOP）

`analyze_t2b.py:64-66`使用`G_F + (v_pi0-v_F) >= -tol`代替`v_pi0-v_F >= -tol`。前者可能让一个比pi0差、但比候选平均好的方案通过。独立脚本附合成反例。当前两个窗口均不满足收益线，所以更正后仍为STOP。

### 3.5 完整状态与探针证据不足

- 一步“真实”对照也直接注入缓存g0，而非独立走完整forward/backward；它验证两种状态装配后的更新一致，不验证整个真实梯度路径。
- `run_t2b_replay.py:134-135,200-204`的别名探针监控g0，但主前缀缓存是后来重新采集的`prefix_grads`；监控对象没进入被声称验证的160次主前缀更新。这是测试覆盖缺口，不等于已经证明主缓存受到污染。
- `VirtualTrack`与真实重复restore复用同一checkpoint payload。PyTorch普通非fused/noncapturable AdamW的`step`张量在load中可能直接引用原张量。独立CPU2.10.0演示复现了step共享；2.11.0官方源码也具有该分支。服务器实际checkpoint的flags与step身份不在包中，应进行零训练检查后定性。
- 若只共享step而m/v分离，从step2048起beta1=.9、beta2=.95的偏差修正已在当前精度下饱和（beta幂约1.94e-94、2.39e-46），故此风险不能被拿来无证据地解释NLL阴性结果。
- 配置有效targets误写76,057,344；2346×32640的正确值为76,573,440，主台账正确。代码另计算了一次g0并执行两个一步探针，应与148个唯一bank、2208主虚拟更新分别记账。

这些缺陷应更正或限定，但目前没有直接证据表明它们推翻主NLL表的有限候选阴性结果。

### 3.6 重复性阈值的解释

`delta_num=max(1e-8,10*e_repeat)`是预设的数值筛查规则；重复差为0不能估计系统舍入偏差或跨后端误差。因此不把1e-8描述成已经实测的普适分辨率，也不由此宣称3e-5在无限精度动力学上显著。它不影响针对当前数值程序与0.001实用阈值的停止判断。

## 4. 数学链条：哪些正确，哪里不能推出效果

### 4.1 实际更新

主矩阵：
M_t=beta M_(t-1)+(1-beta)G_t；
H_t=(1-beta)G_t+beta M_t；
D_t=s Phi_5(H_t)；
W_(t+1)=(1-eta lambda)W_t-eta D_t。

完整状态还包括辅助AdamW的m/v/step；实际G来自全参累积与全局clip。单个beta公式不能代表整个状态系统。

### 4.2 输入波动到更新波动

固定参数、固定初态与确定权重下，Cov(H)=sum_ij w_i w_j Cov(G_i,G_j)是恒等式。小扰动下Cov(D)≈J Cov(H) J^T是局部近似。匹配标量统计却得到不同输出的T0反例，证明统计描述可能缺信息，不证明真实任务具有足够大的可利用差异。

### 4.3 更新波动到目标

在目标的有效局部展开中，E delta V≈q^T mu + (1/2)mu^T K mu + (1/2)tr(K C)+余项。trace(C)变化没有确定目标变化的符号；均值、方向、曲率、状态非线性和后续反馈都不可省略。

### 4.4 公共尾部

真实尾部满足delta M_(t+1)=beta delta M_t+(1-beta)[G_C(theta_t^pi)-G_C(theta_t^0)]，不是只剩beta delta M。

把共同尾部全状态映射记为Psi_C，目标对前缀末态的局部读出由lambda_K=(D Psi_C)^T P_theta^T grad V(theta_T^0)决定。目标差小可能来自前缀扰动小、尾部某些方向收缩、目标梯度投影小、或项间抵消。没有成对状态与响应分解，不能唯一归因。

## 5. 两个不同的近似失效，不要混在一起

T2a：在真实H自然幅度上，一个固定参考点的NS Jacobian线性化不够。

本轮：保留完整NS非线性解决了上一项的一部分，但把全部138步梯度固定在theta*，仍删除了参数变化对梯度的反馈。

g_B(theta_t)=g_B(theta*)+H_B(theta*)(theta_t-theta*)+高阶项。

完全忽略第二项后，优化器内部再精确也不是真实训练动力学。

一个不涉及Muon的合成反例：V(theta)=theta²/2，theta0=1，eta=.1，T=30。真实梯度下降终点V≈0.0008985；始终使用g(theta0)=1的冻结回放终点theta=-2，V=2。故开环回放失效不需要混沌、BF16或物理异常。

S_lin的问题又多一层：它用grad V(theta*)评价围绕virtual_theta_pi0_138的候选差。正确局部基点应该是对应参考终点；只有整段共同位移足够小时，起点梯度才可近似替代。虚拟终态与起点的距离约29，且同Q_select损失显著改变，原方案没有建立这个近似。

## 6. 研究设计为什么没有足够的正信号依据

1. 本轮是每batch64A+64B、32768slots的已混合完整批次。它没有改变域配额，不能继承AB/BA单域块的强驱动差异。在冻结线性平均的简化模型下，域均值差相关项已被固定quota排除；实际组内异质性和相关仍可能存在，尚未量化目标投影。
2. 仅在一个训练末态、末步LR平台下排列十步，随后128步共同更新。这是“小脉冲是否持久”的筛查，不是训练全程持续排序算法的测试。
3. 8个随机排列没有验证输入方向—时间统计差异覆盖范围，也没有实施新方向模型。不能把此次失败写成方向相关统计普遍无决策价值。
4. 两个窗口同checkpoint同种子，不能当成两种训练情境的独立确认。
5. step10候选极差已低于阈值，不能只怪尾部冲淡；同时实际尾部平均NLL仍下降约0.01064/0.00939，不能说模型已完全收敛、什么都改不动。
6. 干预K=10、总轨迹T=138，干预约占7.25%。这个比例本身不能证明无效，但明确了本轮只测试一次性短干预。

先前助手设计也需要承担边界：我们用容易取得的终态和有利于排除瞬态的长公共尾部做了一个保守前提筛查，又把局部回放延伸到138步。它可以帮助停止当前版本，但不足以作为整个物理/数学选题的最终否证。不能在结果出来后自动加LR、换窗口、加方法去救场。

## 7. 参考论文到底支持什么

以下是2026-09-29重新读取的原始来源，包含预印本。它们不是本项目已复现结论。

1. **Optimizer Memory Makes Shuffle Order a First-Order Source of Fine-Tuning Noise**, arXiv:2606.29554v1，Theorem1、Discussion。固定K、eta趋小、连续状态足够平滑且有界、非零replay coefficient，才得到O(eta)局部顺序差；阶数不保证幅度大或可持续。论文明确说独立重洗可平均局部通道，Muon为经验比较，不属于其AdamW闭式保证。不能据此为138步开环终点预测背书。
https://arxiv.org/html/2606.29554v1

2. **Denoise First, Orthogonalize Later**, arXiv:2606.03899v2。结构化信号持续性与扰动假设下，动量先于正交化可改善信号恢复。它对比操作顺序与动量，并不证明在已经使用原生Muon与混合batch时，随机排列里还存在足够大的可选收益。
https://arxiv.org/html/2606.03899v2

3. **Spectral Allocation: Why Muon Outperforms Adam, and How to Improve Muon**, arXiv:2608.25990v1。作者直接探测持出目标方向步长并做有限验证，随后持续修改谱分配。可借鉴“先识别目标相关瓶颈”的链条，不可从谱图不同就移植其收益结论。
https://arxiv.org/html/2608.25990v1

4. **A Physical Response-and-Memory Model for Muon Optimization**, arXiv:2608.22994v1。物理响应与记忆是方法构造工具，双时间尺度方案在整个训练中持续作用；文中明确物理示意不是微观推导。不能把它当作一次性顺序脉冲必有持久收益的保证。
https://arxiv.org/html/2608.22994v1

5. **Move on Muon**, arXiv:2605.23871v1。正则化连续时间/概率流的Hamiltonian耗散，不等于目标单调；目标收敛需梯度支配、动量有界和曲率/对齐等额外条件。不是原生BF16/Nesterov系统的自动性能保证。

## 8. 物理动机与终点收益之间必须补什么

可保留驱动、记忆、松弛、非线性响应等视角，但必须对应可测的目标投影和完整状态。

理想polar满足max_(||D||op<=1)<H,D>=||H||*。这说明它对H作最大局部线性响应；并不保证对验证目标梯度q有相同对齐，更不保证曲率与尾部反馈后保持收益。有限NS还是其不同的数值映射。

观察记忆衰减只能帮助提出机制假设，不能由此报告熵产生、焦耳、FDT破坏，或已证明“末端记忆是唯一原因”。本轮没有相应热力学量测量。

本项目迄今较扎实的是：公式与受控反例的边界、有限NS/数值响应的校准，以及当前候选库的阴性终点结果。尚无可作为新训练方法的有效干预。承认这一点比再次堆叠框架更能保持研究质量。

## 9. 建议的当前处理

- 保持STOP；不追加当前版本的LR、窗口、候选或重复种子来寻找阳性。
- 零GPU修正报告：同目标误差、实际参数位移、状态别名风险、错误门逻辑、记忆归因与有限候选范围。
- 若服务器仍有结果状态，已有文件可补证；不存在时标缺失，不因辅助诊断缺陷默认重跑全部训练。
- 暂停把静态噪声/SNS图作为效果依据的路线。未来重新立项必须先给出真实任务中的目标相关瓶颈、足够强且可部署的干预及对称基线；不能仅以某篇论文或一个toy存在性命题代替预期效应论证。

最终结论：**当前版本的效果前提没有通过；主NLL阴性结果有表内和代码路径支持。失败来自“可观测差异→目标收益”的研究链尚未闭合，以及指定场景/干预没有展现足够效应，不是某个基本数学恒等式被否定，也不是可以直接归因的热力学异常。**
