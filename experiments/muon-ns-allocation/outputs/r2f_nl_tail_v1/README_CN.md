# R2F N→L 尾段对照（AH 特殊性方向的最后一个有界对照）

来源：旧R2 N 中点（s512/s1536_N_step256_full.pt，cursor 768/1792，SHA 与资产证书一致）。
预检：eff_lr=0.5×base、eff_wd=0.02、decay product 比=0.500000（两来源）；无 payload 别名；
L 自身 WD 基点的数据 delta 验证。主分支 512 次更新（2×256）。

主结果（Q_P2_endpoint）：
- s512: J(N,L)=2.721172 vs J(N,AH)=2.721940 → Delta_tail=-7.68e-4（|Δ|<τ=1e-3，不可分辨）
- s1536: J(N,L)=2.491801 vs J(N,AH)=2.491751 → Delta_tail=+4.98e-5（不可分辨）
- G_NL: +5.95e-2 / +1.84e-3（L 尾段远优于继续 N）
- 逐域方向与总体一致。

曲线观察（既有 corrected 快照，只读）：
1. AH 起点领先的反转发生在 rel16→rel64 之间（两起点、两尾部规则一致）；
2. 差距主要在切换后初期（rel1→rel16）快速消解（512 缩水约 90%），非匀速积累；
3. 终点 A/B 域方向一致；中间快照逐域值在 endpoint_values.csv。

结论：固定 AH 的特殊必要性（decay 乘积保持 1）无证据支持——两阶段、两域均与 L 不可分辨。
