## 3. 原理论应怎样修改

### 3.1 保留正确链条，删除无条件收益推论

保留：真实梯度与动量 -> 有限谱变换 -> 更新结构 -> 目标变化。
不成立的无条件推论：更多NS -> 更接近polar -> 更低NLL；或更低正交残差 -> 更高目标收益。

这次的K3/5/7实验不干预batch顺序，因此不是原方向—时间命题的新证实或反驳。它检验的是固定原系数谱映射的局部干预与计算分配。旧T0结果保留为受控机制；旧M2与顺序T3-mini仍关闭。

### 3.2 实际更新

M_l^+=beta*M_l+(1-beta)*G_l；H_l=(1-beta)*G_l+beta*M_l^+。
D_l^(K)=s_l Phi_K(H_l)；u_l^(K)=-eta_l D_l^(K)。
全部探针使用共同完整原生一步为参考，辅助AdamW与WD保持不变；组g包含全部层的同类operator。

### 3.3 改K不是只改变精度

在实数算术和非clamp区，H=U diag(sigma_i)V^T，有
Phi_K(H)=U diag(f^{circ K}(sigma_i/||H||F))V^T，
f(x)=3.4445x-4.775x^3+2.0315x^5。

f(1)=0.701而不是1，因此不能把多做两次该经验多项式当作精确polar收敛保证。改变K同时改变整体幅度、奇异方向之间的相对权重和跨层分布。在实数模型中它保留H的奇异向量，但改变向量化更新的方向；不应随意说“把奇异向量旋转坏了”。BF16还含数值偏差。

### 3.4 统一时钟后的幅度与结构分解

nu5=||u_g^(5)||，gamma=||u_g^(K)||/nu5。
定义共同参考theta0=theta_native^+：
theta_gain=theta0+(gamma-1)u5；theta_raw=theta0+(uK-u5)。
于是精确有
B_raw = B_gain + B_shape@matched-norm，
其中 B_shape@matched-norm = V(theta_gain)-V(theta_raw)。

目标差的望远镜分解不需要泰勒近似或HVP，对既有参数点也严格成立；但将它解释为严格等范数下的结构作用，需要统一时钟并验证实际更新范数。本次表中raw-gain直接给出已测参数点的差值。512/o的有利缩幅约8.90e-5，被结构变化的损失约1.06e-4抵消，raw最终为负。

这不证明所有谱改变都坏；只说明所测K3候选在共同状态/目标上，改变相对结构带来的代价超过了幅度收益。

注意“direction_only”实际上是组级等范数结构比较；可能同时改变组内层间范数分布，并不等于纯旋转，也不是沿单一奇异方向的因果分析。需要正交径向分解时可用 a=<uK,u5>/||u5||²，r=uK-a*u5，满足<r,u5>=0。该系数a不等于norm ratio gamma。

### 3.5 为什么几何指标不决定目标

Y的几何平方残差E²=(1/r)sum_i(s_i(Y)²-1)²，不包含目标梯度或曲率。
在共同native一步后的theta0，对候选增量delta_u有
Delta V = q0^T delta_u + 1/2 delta_u^T Hessian_Q delta_u + R。
减小E不决定q0^T delta_u，更不决定二阶项。局部实验必须直接测有限V，不用E替代。

### 3.6 缩幅现象不等于“训练学习率一定过大”

令 F_g(a)=V(theta0+(a-1)u5_g)。局部展开：
F_g(a)-F_g(1)=(a-1)b_g+1/2(a-1)²c_g+R，
b_g=q0^T u5_g，c_g=u5_g^T Hessian_Q u5_g。

离散a=0.5改善、a=2恶化，可能涉及目标对齐、曲率、batch噪声、域权衡；不单独识别哪个机制。更不能把一步近视目标最优值等同于持续训练预算最优LR。

### 3.7 物理动机的边界

可把梯度当驱动、动量当记忆、谱映射当非线性响应，考察有用目标功与有限步长代价。但这些量单位是loss，不是焦耳；本轮不建立熵产生、温度或FDT违反。

一个受限二次模态模型 V(x)=h*x²/2，h>0，更新x+=x-eta*a*(h*x+xi)，E[xi|x]=0、Var[xi|x]=sigma²，则
E[Delta V|x]=-eta*a*h²*x² + 1/2 eta²*a²*h*(h²*x²+sigma²)。
它说明响应越强不自动越好；只是提出目标对齐/曲率/噪声的可检验假说，不能把Muon奇异基当作Hessian本征基，也不能用该式解释所有观测。

## 4. 文献提供什么与没提供什么

[W1] AMO v2：https://arxiv.org/html/2605.17806v2 。它包含观测、operator预算分配、PE系数重生成、过渡与锁定。本地仅改变原固定quintic的K不等价于该完整方法；Q3仍未测。不能用当前阴性否定AMO，也不能用论文正结果保证本地有效。
[W2] PyTorch v2.11 Muon源码：https://raw.githubusercontent.com/pytorch/pytorch/v2.11.0/torch/optim/_muon.py 。用于核对实际数值更新、缩放与参数组语义，不作为算法收益证据。
[W3] Spectral Allocation / SAMuon：https://arxiv.org/html/2608.25990v1 。值得借鉴的是先连接谱方向与持出目标可接受步长。其配方/主基线不同，不在这轮模拟为本地已复现。

### R1：幅度×结构的最小交叉实验

三个因素：
- a in {0.5,0.75,1.0}：全部Muon数据更新倍率；
- b in {0.75,1.0}：o组额外倍率；
- shape in {NS5原方向, o组NS3经组范数归一后与NS5等范数的结构}。

其余组保持NS5，所有候选共同WD和辅助AdamW原生一步。o组第二种结构定义为 u3_o/gamma_o；实际候选为 a*b*u3_o/gamma_o，与 a*b*u5_o 成对比较。gamma只用于机制诊断，不宣传为免费部署信号。

共12个主候选/校准batch，另加无Muon数据更新(a=0但WD/aux保留)与完整更新前theta_*两个诊断参考，共14。不得把a=0的近视优势解释为应该停止训练。

两个状态×4校准batch×14=112个校准目标点。用Q_select选择以下配置，并锁定后再计算检查：
1. native原配置；
2. global-only最优a（b=1,shape=NS5）；
3. global+o最优(a,b)（shape=NS5）；
4. 在第3项(a,b)下的同范数NS3结构（纯匹配比较）；
5. 全6个(a,b)中校准最优的NS3结构（公平幅度机会，结构化候选）；
6. 无Muon数据更新诊断参考。
检查最多2×4×6=48点；加去重前上限为160点。

所有策略的选择使用固定tie容差及native优先，校准锁定后不得重选。统一输出逐域sum/count、逐batch配对收益、组/全模型更新范数、gamma和额外成本。

主比较：
- group_global_gain_minus_global_only：逐组处理是否提供超出全局幅度的收益；
- matched_shape_minus_group_gain：同a/b/范数下，谱结构是否提供额外收益；
- tuned_shape_minus_tuned_group_gain：两种结构各有相同(a,b)机会后，是否仍有差别。
不能仅用“结构候选比原生好”判定结构有效。

增加目标前后训练batch loss诊断仅针对锁定候选，作为train/目标对齐解释，不用它改选Q目标赢家。数学解释不要求额外全程HVP。
