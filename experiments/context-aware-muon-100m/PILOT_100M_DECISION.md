## 4. 事实性发现（按冻结口径如实报告，不作终点外推）

1. **多矩阵方向混合在 100M/pilot 预算下为负效应**：C_A 两个 λ、自然范数变体、C_B 全部劣于同 LR native Muon；V/O 扩展叠加额外伤害。诊断证实混合真实改变了方向（cos(O_mix,O_nat)≈0.48–0.53，~61–64°）且范数匹配达机器精度 → **负效应归因于方向本身**，即在本训练区把 FFN 更新方向转向当前梯度（λ=0.65/0.85，等效梯度年龄 6.65/2.85 步）**有害**。
2. **与 30M 证据的正面冲突**：30M（0.56 tok/param）中"当前梯度方向修正"对 AdamW 域为正收益、且 Muon 大胜 AdamW 0.27 nats；100M（0.33 tok/param）中 (a) Muon 族全体落后 tuned AdamW ≥0.138，(b) Muon 域的方向混合为负。跨尺度结论**不迁移**，且方向相反。
3. **训练区本质 = 过拟合主导**：全部 15 臂 dev NLL 从 H1024→H4096 单调上升（100M 参数对 33.5M tokens）。次要观察（非主张）：H1024 处各臂大幅接近（6.086–6.304），C_A(0.85) 6.1744 甚至略优于 native Muon 6.1860——混合的伤害主要发生在过拟合相（H2048+），短视界处无优势可言为终点。
4. **tokens-to-threshold 指标在本训练区退化**（阈值=锚点终点 6.4231 低于多数臂的早期值，所有臂在 H1024 即"达标"后恶化）——如实报告退化，不赋予解释力。
5. **同 wall-clock 竞争力**：C_A 吞吐 25.4–27.0k tok/s vs native Muon 31.4–32.0k vs AdamW 36.2–37.8k——候选在 NLL 与速度双输；每 GPU 小时 NLL 改善同样全面落后。
