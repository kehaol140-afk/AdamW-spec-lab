## 1. Group-Muon-A（第一轮主候选）

**作用集**：全部 FFN 矩阵 gate/up/down ×13 层 = **39 矩阵**（各保持原始形状 2432×768 / 768×2432，无转置重塑）。

**每步语义**（对作用集内每个矩阵；其余 52 矩阵 = Q/K/V/O 走 native Muon 位级路径；aux 54 张量走 AdamW）：

```
buf ← μ·buf + (1−μ)·g                # 动量态真值（EMA/lerp 语义；2026-10-12 勘误：原稿误写 μ·buf+g。
                                     # 与 native 完全一致由位级测试锁定，见 MUON_MOMENTUM_EQUIVALENCE.md）
B̃_nat = (1−μ)·g + μ·buf              # native Nesterov 输入（lerp 代码真值）
O_nat = NS5(B̃_nat)                    # 原版 NS5 正交化（同系数同步数）
M     = λ·g + (1−λ)·buf               # 方向混合（当前梯度 × 历史动量）
O_mix = NS5(M)
Δ_mix = −adj_lr · O_mix · (‖O_nat‖/‖O_mix‖)   # fp64 逐矩阵范数匹配（实测 1.4e-16）
θ ← θ·(1−lr·wd) + Δ_mix               # 解耦衰减用原始 lr（torch 语义）
```

- **λ 锚点**：λ₀ = 1−μ = 0.05 时 M ≡ B̃_nat（优化器对该值路由到同一 lerp 表达式，位级等价 native——回归锚）；λ→1 逼近"当前梯度正交化"（Muon 域内的 F-类比）。
- **方向效应单独识别**：范数匹配使逐矩阵位移范数 == native 同步位移范数 → 组间差异纯方向；另设 natural-norm 变体（不匹配）作次级臂。
- **动量解释排除**：low-μ Muon（μ∈{0.9,0.8}，其余 native）对照臂——若其复现收益则记 `MOMENTUM_EXPLAINED`，候选降级。
- **诊断**（fp64；cos 度量必须 fp64，fp32 求和误差 ~1e-4 会伪造/淹没信号——本轮实测教训）：cos(O_mix,g)、cos(O_mix,O_nat)、逐矩阵范数比、NS5 秒（native/mix 分列）。

**第一轮明确不做**：动态谱指数、门控网络、每步 SVD（源码扫描测试强制）、改变 NS 系数/步数。

## 2. Group-Muon-B（扩展候选，仅当 A 有信号）

在 A 基础上把 **Attention V/O ×13 = 26 矩阵**加入混合集（共 65）；Q/K 保持 native（最小惊讶原则：QK-Norm 相邻，先不动）。决策规则：B 与 A 同 λ 比较；B−A 差异 <1e-3 → 记 `VO_EXTENSION_NO_GAIN`，不外推。

## 3. 参数与网格（草案；冻结于 pilot 协议）

| 参数 | 候选 | 说明 |
|---|---|---|
| λ | {0.65, 0.85}（+锚点 0.05=native 等价不重复跑） | 朝当前梯度方向的偏移；0.5 不取（与锚点太近，30M 信号提示需要足够混合量） |
| norm_match | True（主）/ False（单臂次级） | 方向效应主判据 / 自然范数稳健性 |
| LR | 沿用 Muon 最优（同臂内公平） | 候选不单开 LR 网格（第一轮预算纪律；若边界现象出现再议） |
| wd | 0.02（Muon 家族统一） | M 线接线 |

## 4. 第四阶段：矩阵级预算重分配（预设计，A/B 正面信号后才启动）

**分组**：每层 FFN 三矩阵为一组（13 组）+ V/O 为一组（1×13 或逐层 13 组，冻结时定）。

**冻结逐层预算**（该层总更新范数守恒）下，2×2 因子分解：

| 臂 | 方向 | 尺度 | 说明 |
|---|---|---|---|
| D0 | native | native | 标准对照 |
| D1 | mix(λ*) | native | 只有方向变化 |
| D2 | native | 重分配 | 只有尺度变化（组内三矩阵相对倍率，逐层范数守恒） |
| D3 | mix(λ*) | 重分配 | 组合 |

**归因规则**：D3 收益 ≈ D1+D2 之和 → 可加、无谱结构证据；D3 显著超过 → 才允许讨论"方向×尺度协同"；**任何情况下不得把 D3 总收益整体归因于谱结构**（横断教训第 1 条）。尺度重分配参数化为逐矩阵倍率 s_i（Σs_i² 守恒），网格 {0.8, 1.25}（等效单矩阵 ±25% 能量移动），不学习、不动态。

## 5. 与已有 Muon 历史线的边界

- 不重开 K∈{3,5,7} NS 步数分配（msa P0/P1 阴性闭环）；
- 不重开 Head/Bulk 固定谱倾斜（SpecMuon P1 阴性闭环）；
- 不做状态补丁（R2F R_N<0 教训）——mix 是持续配方，每步生效；
- 本候选作用于 **NS5 的输入方向**（混合当前梯度与动量），与"整形 NS5 输出谱"（已关闭）和"重分配 NS 预算"（已关闭）均不同域；与 V16 F/P（AdamW 域）同构——把"当前梯度方向优于动量商方向"的 4.66M 证据迁移到 Muon 几何域检验。
