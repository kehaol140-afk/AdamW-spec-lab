# 100M_COMPUTE_AND_MEMORY — 计算与内存预算（本轮 smoke 实测口径）

- 日期：2026-10-12。**全部锚点为本项目 100M 实测**（MULTI_MATRIX_OPERATOR_TESTS §3）；旧 100M 准备报告（cross_scale_100m_prep_20261011）口径已按任务书作废。
- 硬件：GPU0 RTX 5090 32G 单卡（GPU1 外部占用）；RAM 108G 空闲；磁盘 148G 空闲。

---

## 1. 实测锚点（30 步 × 8192 tok/步）

| 路径 | s/步 | tok/s | VRAM 峰 |
|---|---|---|---|
| AdamW | 0.320 | 25.7k | 3.35 GiB |
| native Muon+aux | 0.283 | 29.1k | 3.02 GiB |
| Group-A（含每步 fp64 诊断） | 0.345 | 23.8k | 2.98 GiB |
| Group-A（诊断降采样后预估） | ~0.30（估） | ~27k（估） | ~3.0 GiB |

不确定性：30 步均值含 Python 循环开销；正式 pilot 前 100 步复测（含首步编译/分配）。

## 2. 内存

| 项 | 值 |
|---|---|
| 参数 fp32 | 403 MiB |
| AdamW moments（m+v，全参数） | 806 MiB |
| Muon 动量 buffer（91 矩阵 fp32） | 403 MiB |
| 训练 reserved 峰值（实测） | **2.98–3.35 GiB**（批 8192 tok/步；批放大线性外推：32,768 tok/步 ≈ 6–9 GiB，仍充裕） |
| 优化器状态额外持久化 | Group-A 与 native 相同（mix 不加状态） |
| token 缓存 | smoke 1.2M（4.8MB）；pilot 33.6M（134MB）；确认 100–300M/seed（0.4–1.2GB） |
