# MOE_EXTENSION_DESIGN — MoE 扩展设计（仅 CPU 级，零 GPU）

- 日期：2026-10-12。**本轮零 MoE 训练、零 MoE 代码执行**；本文是架构/算法设计 + 必要统计设计。
- 结构参照：minimind_base MiniMindConfig（use_moe=True：num_experts=4、num_experts_per_tok=1、moe_intermediate_size、norm_topk_prob、router_aux_loss_coef=5e-4）——**本项目尚未实例化 MoE 配置，以下为设计文档，非实测**。

---

## 1. 六类参数的严格区分（任务书要求；勿与优化器参数分组混淆）

| 类别 | 张量（以 4 专家 / top-1 / h768 为例） | 优化器归属（设计） | 与密集线的对应 |
|---|---|---|---|
| 密集 FFN（非 MoE 基线） | gate/up/down ×13 | Muon（39 矩阵） | 现有 Group-A/B 直接适用 |
| Shared experts（若启用） | gate/up/down ×N_shared | Muon（每步激活，无稀疏性问题） | 同密集 FFN 处理 |
| Routed experts | 每专家 gate/up/down ×4 = 12 矩阵/层 | Muon，**但梯度稀疏**（top-1 路由下每步仅 1 专家/层有梯度） | Group 语义需重定义（§3） |
| Router 权重 | gate(hidden→num_experts) 2D | **AdamW（aux）**——路由器是小矩阵，正交化语义可疑且影响路由分布稳定性；Moonlight 实践同向 | 新增 aux 类 |
| Attention | q/k/v/o ×13 | Muon（不变） | Group-B 的 V/O 子集语义保留 |
| 辅助 AdamW 参数 | embed（tied head）、final_norm、q/k_norm、ln ×13、（新）router | AdamW | 现有 aux 扩展 |

**红线重申**：现有 Muon/AdamW 参数分组（ffn/vo/qk/aux）是**优化器路由**，不是 MoE 专家计算路由；两者叠加时逐张量判定，禁止把"Muon 组"误称为"专家组"。

## 2. 稀疏激活下的 Muon 语义问题（核心分析）

top-k 路由（k=1）下，每个 routed 专家矩阵**仅在被选中时收到非 None 梯度**：

1. **动量新鲜度**：Muon 动量 buffer B_e 对专家 e 只在其激活步更新 → B_e 是"陈旧动量"（年龄 a_e 步）。native Muon 的隐含假设（B 平滑近期梯度）被破坏：B_e ≈ μ^{a_e}·(旧方向)。
2. **NS5 输入退化**：长期未激活专家的 B̃ = (1−μ)g+μB_e 中 B_e 贡献按 μ^{a_e} 衰减——**天然趋向当前梯度方向**（相当于自动 λ→1−μ^{a_e}·μ…即混合锚点随陈旧度漂移）。这既是风险（不同专家实际跑在不同有效 λ 上）也是机会（方向混合家族恰好参数化了这个维度——可在 MoE 域显式控制）。
3. **范数匹配参照缺失**：norm-match 需要同步 native 参考 NS5——对未激活专家无当步梯度，参考不存在；设计上范数匹配只在激活步执行（参照该专家自身 native 路径），跨专家无匹配（不同专家更新频率本就不同）。
4. **路由-优化器耦合**：更新几何改变专家表示 → 改变 router 打分 → 改变激活分布（反馈环）。任何 MoE 域结论必须同时报告路由统计（§4），否则无法归因。

## 3. Group-Muon 在 MoE 域的扩展设计（候选，未实现）

- **G-MoE-A（逐专家混合）**：每个专家的 3 矩阵独立按 Group-A 语义（激活步：M=λg+(1−λ)B_e）。λ 可与密集域共享（同 λ 先验）或按专家陈旧度自适应——**第一轮禁自适应**（同密集域纪律），只用全局 λ。
- **G-MoE-B（专家内组正交化）**：把单专家 gate/up/down 拼接视为层内多矩阵组…… **设计上明确拒绝**：拼接破坏"保留各矩阵原始形状"红线（块对角正交化 ≠ 逐矩阵正交化，语义为新算子，超出第一轮）。
- Router/aux 不进任何 Muon 组。

## 4. 必要统计（MoE 实验的最低观测集）

| 统计 | 定义 | 用途 |
|---|---|---|
| 专家激活计数 | n_e(step) 与占比 p_e；负载熵 | 路由塌缩/偏置检测 |
| 梯度历史一致性 | 激活步 cos(g_e, B_e)（fp64）；B_e 年龄分布 a_e | 陈旧动量量化（§2.2 的实测版） |
| 未激活专家状态管理 | (a) 保留 buffer（默认）；(b) 激活时衰减 μ^{a_e} 重标定——两种策略登记，第一轮只跑 (a) 并测量 | 决定是否需要 (b) |
| 路由-损失耦合 | 负载熵 vs NLL 轨迹；aux_loss 分列 | 反馈环监测 |
| 逐专家更新范数 | 激活步 ‖Δ_e‖（范数匹配后） | 公平性验证 |

## 5. 进入条件与不做

- 进入条件：密集 100M 线 Group-A/B 在 pilot/确认层取得正面信号 + 上述统计在密集线锚点步管道已验证 + 用户单独授权；MoE 配置先经 CPU 实例化审计（参数计数/路由张量清单/tied 检查）。
- 不做：本轮任何 MoE GPU 训练；自适应 λ；拼接式组正交化；把参数分组当专家路由。
