# TRAINING_COST_ESTIMATE — 训练成本估算

基准实测（V16 服务器同平台 RTX 5090 / fr_minimind，2026-10-10）：
- 从头 2048 步 + 3 次 dev 评估 ≈ **12.5 分钟/臂**（B 阶段 18 臂 3.6h 实测）
- 4096 步 + 4 次 dev 评估 + 1024 文档 holdout ≈ **26 分钟/臂**（C 阶段 6 臂 2.4h 实测）
- VRAM reserved ~0.22 GiB / RSS ~2.0 GiB（全程稳定）

## Layer 1（5 臂 × 2048 步）

| 项 | 估算 |
|---|---|
| 训练 | 5 × 11.5 min ≈ 58 min |
| 评估 | 5 × (3 × dev 256 文档 + 1 × screen 256) ≈ 6 min |
| 锚点 SVD（5 臂 × 4 锚 × 3 矩阵 = 60 次，~ms 级） | 忽略 |
| **合计 GPU** | **~65 min**（上限 90 min 容错） |
| 磁盘 | 步日志 ~5×1.5MB + 端点 5×18MB ≈ 120 MB |
| RAM/VRAM | RSS ~2 GiB / reserved ~0.25 GiB |

## Layer 2（仅当 gate 通过；4 臂 × 3 seeds × 4096 步）

| 项 | 估算 |
|---|---|
| 训练 | 12 × 23 min ≈ 4.6 h |
| dev 评估（4 视界 × 12）+ holdout_v2（≤1024 文档 × 12） | ≈ 0.6 h |
| **合计 GPU** | **~5.2 h**（上限 7 h 容错） |
| 磁盘 | 端点 12×18MB + 日志/eval ≈ 400 MB |
| 数据 | 每 scratch 臂消耗 8,388,608 token ≤ 缓存 8.5M（恰好覆盖，多臂共用同流 CRN） |

## 两层合计 ≈ 6.5 h GPU（+10% 容错 ≈ 7.2 h）

排程约束：GPU0 本轮归 SpecMuon P1 优先；本估算仅用于未来授权与排队，不启动任何任务。墙钟预算建议：单层一次性连续跑完（layer-1 ~1.5h 墙钟、layer-2 ~6h 墙钟），避免跨天中断。
